# Silicon Valley Marble

A five-level 3D marble platformer for desktop browsers: roll from a data center to the post-ASI future, collecting gems against the clock.

**Play:** https://katiegoldstein.github.io/silicon-valley-marble/

WASD or arrows to roll · mouse to look · Space to jump · click to use a power-up · R to restart · Esc to pause

Built with three.js, Rapier and Vite. Run it locally with `npm install` then `npm run dev`.
